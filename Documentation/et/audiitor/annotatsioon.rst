..  IVXV collector service management service description

Abstract
--------

This guide provides instructions for performing an IVXV data audit on the Ubuntu 20.04 platform.
It is useful to familiarize yourself with the following documents.

* https://www.valimised.ee/sites/default/files/uploads/eh/IVXV_raamistiku_yldkirjeldus_29052017.pdf
* https://www.valimised.ee/sites/default/files/uploads/eh/IVXV-seadistuste-koostejuhend.pdf
* https://www.valimised.ee/sites/default/files/uploads/eh/IVXV-protokollid.pdf

The guide is accompanied by a sample data set and a free-form `history` file.
