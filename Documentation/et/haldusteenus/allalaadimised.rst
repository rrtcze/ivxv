.. _allalaadimised:

Downloading extracts
=====================

The extracts download page opens from the menu option ``Allalaadimised``.


Downloading detailed voting statistics
---------------------------------------

The detailed statistics are in JSON format and are generated by the voting service.


Downloading voting sessions extract
-------------------------------------

The voting and vote verification sessions extract is in CSV format and is
compiled by the log monitoring service.


Downloading the e-ballot box
-----------------------------

On the e-ballot box download form, it is possible to:

* Initiate the compilation of the e-ballot box;

* Download compiled e-ballot boxes.

The e-ballot box can be compiled in unconsolidated and consolidated form.
Consolidation is a resource-intensive operation and should only be used
if there have been problems with the storage service during vote collection.

The e-ballot box downloaded before the end of the voting period is intended for backup purposes;
the e-ballot box downloaded after the end of the voting period is intended for vote
counting.

.. attention::

   Compiling the e-ballot box can be a time-consuming operation! It depends on the number
   of collected votes, the number of backed-up e-ballot boxes, the hardware
   capabilities of the service machines, the throughput of the network connecting the
   service machines, and the system load.


Downloading the processing application input base
---------------------------------------------------

The processing application input base is a set of input files required for vote
processing in ZIP format as a container, and it is compiled by the management service.
